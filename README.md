# Landing de ¿Qué sale?

Versión estática lista para desplegar con GitHub Pages. No necesita instalación, compilación ni backend.

## Contenido

- `index.html`: página principal.
- `styles.css` e `identidad-cereza.css`: estilos base e identidad cereza/azul marino.
- `script.js`: menú móvil y animaciones ligeras.
- `assets/logo-quesale-cereza.png`: símbolo de llama y birrete.

## Publicación con GitHub Pages

1. Sube el contenido de esta carpeta al repositorio o a una rama dedicada.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama que contiene esta landing y la carpeta **/(root)** si esta carpeta será la raíz del repositorio; si se mantiene dentro de un repositorio con más archivos, usa una rama dedicada cuyo contenido sea esta carpeta.
5. Guarda los cambios y espera la URL que muestra GitHub Pages.

No se debe seleccionar la carpeta `landing/` desde la interfaz de GitHub Pages: Pages permite raíz o `/docs`. Por eso la alternativa más sencilla es una rama dedicada que contenga exactamente estos archivos.
